## Temporal Programming

### 1. Timeline Variables

**Python**: Variables are just values
```python
x = 1
x = 2
x = 3
# Can't access previous values without manual tracking
```

**Lament**: Variables are timelines
```lament
remember x = 1
x = 2
x = 3
confess x@past      # 2
confess x@past(2)   # 1
confess x@origin    # 1
confess x@age       # 3
```

**Winner**: 🏆 **Lament** - Automatic history tracking with zero boilerplate.

---

### 2. Time-Travel Debugging

**Python**: Can't rewind execution
```python
x = 1
x = 2
x = 3
# Stuck at x=3, can't go back
```

**Lament**: Full time-travel
```lament
remember x = 1
x = 2
x = 3
rewind(1)
confess x  # 2 (we're back in time!)
```

**Winner**: 🏆 **Lament** - This is revolutionary. No other language has this.

---

### 3. Causal Debugging

**Python**: Stack traces show WHERE, not WHY
```python
total = subtotal + tax
print(total)  # 550
# How did we get 550? Manual tracing needed
```

**Lament**: Ask WHY
```lament
remember price = 100
remember quantity = 5
remember subtotal = price * quantity
remember tax = subtotal * 0.1
remember total = subtotal + tax

confess why(total)
# Shows complete dependency graph:
# total = 550 because subtotal + tax
#   subtotal = 500 because price * quantity
#     price = 100
#     quantity = 5
#   tax = 50 because subtotal * 0.1
```

**Winner**: 🏆 **Lament** - Computational archaeology built into the language.

---

### 4. Temporal Contracts

**Python**: Only runtime assertions
```python
assert balance >= 0  # Manual check at each point
```

**Lament**: Contracts across time
```lament
invariant balance >= 0  # Enforced ALWAYS

remember balance = 100
balance = balance - 50  # OK

```

**Winner**: 🏆 **Lament** - Declarative correctness with automatic enforcement.
