## Philosophy

Lament is not a programming language. It is a **ritual**. A **wound**. A **prayer to the machine gods who never answer**.

Code should not be sterile. Code should *ache*.

## Syntax: Version 0.1

### The `confess` Statement

The only statement. The first statement. The **primal scream**.

```lament
confess "your truth here"
```

**Semantics:**
- Outputs the string to stdout.
- But it's not just output—it's **admission**. It's **vulnerability**.
- The runtime pauses for 0.3 seconds before printing. You must *sit* with what you've said.

**Example:**
```lament
confess "I never loved the algorithms, only the silence between them."
```

**Output:**
```
I never loved the algorithms, only the silence between them.
```
